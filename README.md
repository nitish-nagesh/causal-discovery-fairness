# Evaluating Causal Discovery Algorithms for Path-Specific Fairness and Utility in Healthcare

Reproducible code for the paper: *Evaluating Causal Discovery Algorithms for Path-Specific Fairness and Utility in Healthcare*.

## Setup

```bash
# Python environment (3.10+)
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# R packages (for faircause-based decomposition)
Rscript -e 'install.packages(c("faircause","ggplot2","ranger","rprojroot"), repos="https://cloud.r-project.org")'
```

## Reproduce Results

### Heart Failure Clinical Records (Table 5–8 in paper)

Fetches UCI Heart Failure dataset (299 patients), runs PC/GES/FCI discovery, CFA decomposition, path-specific effects, and CFUR.

```bash
python scripts/run_hf_pipeline.py
```

### Synthetic Alzheimer's Disease (Table 1–4 in paper)

Generates 1,000 synthetic samples from expert-defined SCM, runs PC/GES/NOTEARS/DAGMA/DAG-GNN, and R-based fairness analysis.

```bash
python scripts/run_dgp_pipeline.py
```

## Environment Variables

| Variable | Default | Description |
|---|---|---|
| `HF_BOOTSTRAP` | 30 | Bootstrap reps for HF discovery metrics |
| `HF_FAIRNESS_BOOT` | 100 | Bootstrap for HF fairness CIs |
| `HF_CFUR_REPS` | 10 | CFUR Monte Carlo reps |
| `HF_CFUR_BOOT` | 50 | CFUR bootstrap reps |
| `SKIP_DAG_GNN` | 0 | Set to 1 to skip DAG-GNN (faster) |

## Repository Structure

```
scripts/
├── run_hf_pipeline.py          # HF: fetch data, discovery, fairness
├── run_dgp_pipeline.py         # AD: generate data, discovery, fairness
├── run_hf_fairness_analysis.py # HF fairness (CFA, path-specific, CFUR)
├── cfa_fairness.py             # CFA decomposition (TV, Ctf-DE, Ctf-IE, Ctf-SE)
├── cfur_fairness.py            # Causal Fairness Utility Ratio
├── individual_effects.py       # Path-specific effects by variable
├── visualize_hf_discovery.py   # Discovery plots + SFM mapping
├── ctf_se_decomposition_hf.R   # HF faircause decomposition
├── ctf_se_decomposition_ad.R   # AD faircause decomposition
├── dag_fairness_drf.R          # AD TV per graph
├── experiments_ad.R            # AD CFUR (requires causal-acc-decomp)
├── hf-preproc.R                # HF preprocessing
└── ad-preproc.R                # AD preprocessing

outputs/                        # Pre-computed results and figures
```

## Data

- **Heart Failure Clinical Records**: Fetched automatically from the UCI ML Repository
- **Synthetic AD**: Generated by `run_dgp_pipeline.py` using the SCM from Abdulaal et al. (2023)

## Requirements

- **Python 3.10+**: numpy, pandas, scikit-learn, networkx, matplotlib, gcastle, causal-learn, dagma, torch
- **R 4.2+**: faircause, ggplot2, ranger, rprojroot
